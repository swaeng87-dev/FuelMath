Engineering Methodology & Standards

Every FuelMath calculator executes 100% client-side and documents its governing equations, reference constants, and assumptions. This page indexes the methodology behind each tool.

Reference Conditions

Unless stated otherwise, all gas volume calculations use standard reference conditions of 15°C (288.15 K) and 101.325 kPa per ISO 13443.

Primary Standards Used

  • ISO 13443 / ISO 6976 — Natural gas reference conditions & calorific value calculation
  • AGA Report No. 8 / ISO 12213 — Real gas compressibility (Dranchuk–Abu–Kassem)
  • AGA Weymouth & Panhandle A/B — Gas transmission pipeline flow
  • ASTM D1250 / API MPMS 11.1 — Petroleum volume & density correction
  • ASTM D240 / D445 / D341 / D5865 — Calorific value, viscosity, blending, solid fuels
  • IPCC AR6 — Global Warming Potentials (CH₄: GWP₁₀₀ = 29.8, GWP₂₀ = 82.5)
  • ISO 8528 / ISO 22241 / ISO 8217 — DG sets, DEF/AdBlue, marine fuels
  • SAE J1349 / NIST HB 44 — Engine power testing, fuel energy equivalence

Estimation Disclaimer

Simplified correlations are clearly labeled on each tool page. Critical industrial, custody-transfer, or safety operations must be verified by a licensed professional engineer.
