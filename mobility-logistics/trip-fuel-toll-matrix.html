Methodology & Formula

Accurate trip budgeting requires adjusting baseline mileage for payload-induced efficiency losses. Loaded vehicles burn more fuel per kilometer due to increased rolling resistance, greater inertial mass during acceleration, and higher drivetrain loads.

Step 1 — Payload-Adjusted Mileage

Mileageeff = Mileage × (1 − Penalty / 100)

Step 2 — Fuel Required

Vfuel = Distance / Mileageeff

Step 3 — Total Journey Cost

Total = (Vfuel × Price) + Tolls

  • Distance = One-way trip distance (km) — double for round trips
  • Mileage = Baseline unloaded efficiency (km/L)
  • Penalty = Payload efficiency loss (%) — select from the reference table based on load state
  • Tolls = Sum of all toll plaza charges along the route

Reference: Route Logistics Fuel Matrix Model

The route logistics fuel matrix model aggregates distance, load state, terrain profile, and regional pricing into a single journey cost figure. For multi-stop routes with varying fuel prices across regions, use the Fleet Route Optimizer to identify the cheapest refueling strategy.
