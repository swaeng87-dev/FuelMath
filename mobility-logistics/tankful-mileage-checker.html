Full-to-Full Audit Protocol

1. Fill tank to auto-stop; record odometer.

2. Drive normally until next fill-up.

3. Fill to auto-stop again; record litres + odometer.

4. True mileage = distance ÷ litres.

5. Compare against dashboard figure for tampering.

Methodology & Formula

The full-to-full method is the gold standard for measuring true fuel economy. Unlike onboard trip computers — which estimate from injector pulse data and can drift or be manipulated — the pump-measured volume and odometer distance give a ground-truth figure.

Distance Covered

Distance = Odometerend − Odometerstart

True Fuel Economy

Mileage = Distance / Litres

Cost per Kilometer

Ckm = (Litres × Price) / Distance

Discrepancy vs. Dashboard

Δ% = ((Mileage − Dashboard) / Dashboard) × 100

  • Full-to-full = fill to pump auto-stop at both readings to eliminate partial-tank error
  • Discrepancy near 0% = dashboard is accurate; no tampering suspected
  • Negative Δ% = true mileage is below dashboard — investigate fuel theft, leaks, or ECU calibration
  • Positive Δ% = true mileage exceeds dashboard — trip computer is conservative (common, usually harmless)

Anti-Tampering Guidance

If the discrepancy is consistently negative across multiple tankfuls, cross-check with fuel receipts, inspect for siphoning or line leaks, and verify the trip computer hasn't been recalibrated. For fleets, log each tankful in the Driver Fuel Performance Grader to track trends per vehicle and driver.

Reference Standard: Full-to-Full Fuel Economy Audit Protocol

The full-to-full audit is the field-standard method endorsed by fleet managers and fuel-control officers for verifying real-world consumption. It is independent of manufacturer trip-computer estimates and forms the basis for fuel-theft detection, warranty mileage claims, and driver performance benchmarking.
