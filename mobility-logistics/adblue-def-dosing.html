Methodology & Formula

Selective Catalytic Reduction (SCR) systems inject Diesel Exhaust Fluid (DEF, marketed as AdBlue) into the exhaust stream to convert NOx into nitrogen and water. DEF consumption is directly proportional to diesel burn, typically at 3–5% of fuel volume.

DEF Consumption

VDEF = Diesel × (Dosing Rate / 100)

DEF Operating Cost

Cost = VDEF × DEF Price

Refill Interval (Tank Range)

Refill Every = Tank Capacity / VDEF

  • Dosing Rate = DEF injected as % of diesel volume — set by the SCR control unit based on NOx load
  • Refill Interval = number of periods one full DEF tank lasts before topping up
  • DEF is a 32.5% urea solution in deionized water; it is consumed slower than diesel, so DEF tanks are sized smaller
  • Running the DEF tank dry triggers vehicle derate/limp mode in most modern SCR systems — never let it empty

Fleet Planning Note

For fleets, multiply DEF consumption by vehicle count and plan bulk AUS 32 procurement. DEF degrades with heat and time (≈12-month shelf life at 25°C), so size bulk orders to turnover within that window. Contaminated or off-spec DEF can damage SCR catalysts and void warranties.

Reference Standard: ISO 22241 (AUS 32 / DEF Quality Standards)

ISO 22241 defines the quality requirements, test methods, and handling for AUS 32 (Aqueous Urea Solution 32.5%), marketed as AdBlue in Europe and DEF in North America. Correct DEF quality and dosing are essential for emissions compliance (Euro 6 / EPA 2010 and later) and SCR system longevity.
