Methodology & Formula

Petroleum density is temperature-dependent — liquids expand when heated, reducing measured density. All commercial petroleum transactions use density corrected to the standard reference temperature of 15°C (60°F). This tool applies a linear thermal expansion correction followed by the API gravity conversion.

Step 1 — Temperature Correction to 15°C

ρ₁₅ = ρT × (1 + α × (T − 15))

Step 2 — Specific Gravity at 60°F

SG = ρ₁₅ / 999.0

Step 3 — API Gravity Conversion

°API = (141.5 / SG) − 131.5

  • ρT = Observed density (kg/m³), T = Observed temperature (°C), α = Volumetric expansion coefficient (1/°C)
  • 999.0 kg/m³ = Density of water at 15°C (API reference base)
  • API gravity is inversely related to density: lighter crudes have higher °API values

Model Limitation

This tool uses a linear expansion approximation suitable for field estimates and small temperature deltas (±20°C from base). For custody-transfer precision, the full ASTM D1250 Table 54 algorithm uses product-specific coefficients and non-linear VCF interpolation. Always use certified VCF tables for contract settlement.

Reference Standard: ASTM D1250 / API MPMS Chapter 11.1

ASTM D1250 and API MPMS Ch. 11.1 define the Petroleum Measurement Tables used globally for volume and density correction. The API gravity scale was established by the American Petroleum Institute and remains the universal crude oil quality metric in trading and refining.
